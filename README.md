# MonsterRancher2
Monster Rancher 2 / 2DX Errantry simulation to calculate the odds to learn techs per stage and overall.
Legend Cup only displays the odds to learn per stage, not per Errantry, and not with notification unless you scroll down.
The Errantry calculations for one tech are simple and show the true odds to learn on Errantry are 1.5 to 4.0x greater than the stage odds. The relationship is non-linear.

I was able to spreadsheet out primary and secondary tech odds and simulate to back the odds up. This is the simulation. Finally can know what the odds of learning, say, Phantom Claw or Twister Claw for Kato when Phantom Claw has priority and both have an auto-learn chance of 3%.
